## About

I am a Python developer in Moscow. Python is home base. C, C++, C#, Lua, and Rust are how I get closer to a runtime, a launcher, or a service.

Right now that means language modules for [NodeMP](https://github.com/Igor20264/NodeMP-C_ABI-Python): CPython and LuaJIT on a C ABI. Scripts talk to the server through a global `node`, and long work can leave the game tick and run on a thread pinned to one core.

Around that I build FastAPI and Flask services, Telegram bots, and desktop tools.

## По-русски

Я пишу на Python и живу в Москве. Python — основная работа. На C, C++, C#, Lua и Rust перехожу, когда нужен хост, лаунчер или сервис.

Сейчас это языковые модули NodeMP: CPython и LuaJIT на C ABI. Скрипт видит глобальный `node`, а долгая работа уходит с игрового тика на поток, закреплённый за одним ядром.

Рядом сервисы на FastAPI и Flask, боты Telegram и настольные утилиты.
